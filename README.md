# 🔐 Crack the Code — Participant Console

Participant-facing web application for the "Crack the Code" gamified event.

## 🚀 Quick Start

1. Edit `config.js` to point `API_BASE` at your backend server URL (e.g. `http://localhost:4000` or your server's IP address):
   ```javascript
   const API_BASE = "http://localhost:4000";
   ```
2. Open `index.html` in any modern web browser to join and compete in released event rounds.

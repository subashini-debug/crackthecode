# 🔐 Crack the Code — Backend Server

Backend Node.js + Express + Socket.IO server for the "Crack the Code" platform.

## 🚀 Deployment Instructions (Render / Railway / Koyeb / Heroku)

1. **Root Directory**: `./`
2. **Build Command**: `npm install`
3. **Start Command**: `npm start`
4. **Environment Variables**:
   - `ADMIN_KEY`: `admin123` (or your custom admin key)
   - `GEMINI_API_KEY`: `your_gemini_api_key_here`
